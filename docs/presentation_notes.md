# 复现部分汇报提纲

## 建议讲法

这一部分回答三个问题：

1. 我们能否从论文公开的空间表达矩阵重新得到可信的质量指标和组织结构？
2. 独立的植物表达聚类是否能对应作者的组织分区？
3. 同一空间 bin 内能否同时看到植物和根瘤菌信号？

## 页面结构

### 1. 复现范围

- 案例：*Cell* (2026) 苜蓿根瘤 Stereo-seq 共转录组。
- 使用一个代表性 P3、14 dpi 切片。
- 从公开 `.h5ad` 的计数层开始，不重跑 FASTQ 比对，不做湿实验。
- 四项内容：QC/标准化、独立聚类、标记基因、植物–根瘤菌计数拆分。

建议配图：论文 Figure 1A 的工作流 + 本仓库 `README` 的分析流程图。

### 2. 数据质量

- 1,284 个空间 bin，40,160 个基因。
- 34,349 个植物基因，5,811 个根瘤菌基因。
- bin 总计数中位数 1,790；检测基因中位数 770。
- 坐标、组织标签、基因 ID 和计数守恒检查均通过。
- 根瘤菌占比必须在总测序深度背景下解释。

建议配图：`results/figures/01_qc_overview.pdf`。

### 3. 独立聚类

- 只使用植物基因，避免细菌占比直接决定组织聚类。
- 2,000 HVG、20 PCs、15 neighbours、固定随机种子 42。
- 分辨率 0.3 得到 3 个簇，分辨率 0.8 得到 6 个簇。
- 0.8 分辨率的 ARI = 0.199、NMI = 0.300。
- 两档聚类的 PCA silhouette 均约 0.068；空间 6-近邻同类比例分别为 0.784 和 0.579。
- 空间结构清晰，但不复制作者标签；作者注释使用完整多切片和人工证据。

建议配图：

- `results/figures/03_independent_clustering.pdf`
- `results/figures/03b_cluster_annotation_confusion.pdf`

### 4. 标记基因

- 根据论文 Table S1-5 和 Mt5.0 官方注释解析 9 个标记。
- `MtPLT3/MtPLT4` 富集于分生区。
- `MtNOD25/MtLb6/MtENOD8.1` 在感染区有清晰空间信号。
- 4/9 个标记在本 P3 切片中的最高区域与跨阶段预期完全一致。
- 9/9 个标记都能在 Table S1-5 和 Mt5.0 官方注释中完成双重核对。
- 部分不一致说明单切片区域边界、相邻组织标签和跨阶段注释需要谨慎对待。

建议配图：

- `results/figures/04_marker_dotplots.pdf`
- `results/figures/05_marker_spatial.pdf`

### 5. 植物–根瘤菌共检测

- 根瘤菌占比 = 根瘤菌计数 /（植物计数 + 根瘤菌计数）。
- 本切片中位占比较高的区域是 Interzone、Distal infection zone 和
  Proximal infection zone。
- 固氮区中位占比低于感染区；这与论文跨阶段趋势不完全相同。
- 比例受测序深度、RNA 组成和捕获效率影响，不是细菌数量或固氮效率。
- 区域统计检验仅作描述性辅助，空间 bin 不是独立生物学重复。

建议配图：`results/figures/06_rhizobia_fraction.pdf`。

### 6. 总结

- 公开数据可以支持可重复的单切片级空间转录组重分析。
- 独立分析复现了空间结构，但没有完全复现作者注释。
- 单切片结果不能替代完整 20 个切片整合、发育轨迹和实验验证。
- 完整代码、参数、日志、结果表和从零运行 Notebook 已公开在 GitHub。

## 两分钟口述版

> 我们选择了论文里的一个 P3 根瘤切片做局部复现。数据共有 1,284 个空间 bin 和
> 40,160 个基因，同时包含苜蓿和根瘤菌计数。首先，我们从原始计数层重建质量指标；
> 然后只用植物基因做标准化、降维、聚类和空间定位。独立聚类能分出清楚的组织区域，
> 但与作者标签的一致性只有中等偏低，ARI 大约 0.20，这说明作者注释还结合了跨切片
> 和人工证据。接着，我们用论文 Table S1 和 Mt5.0 注释映射区域标记基因，分生区、
> 感染区标记有明确的空间富集。最后，我们按物种拆分计数，发现感染区和交界区的
> 根瘤菌计数比例较高。需要强调，这个比例不是细菌数量，也不能直接代表固氮效率；
> 我们的结论是单切片能够复现方法链条和空间结构，但不能替代论文的完整多阶段分析。
